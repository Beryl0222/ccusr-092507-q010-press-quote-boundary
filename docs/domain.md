# 领域约定

描述新闻交流场次中的提问、回答、翻译、引用级别和更正关系，支持多语言引语追溯。

聚合对象包括`press_session`、`question_turn`、`quote_fragment`、`correction_notice`。事件类型包括`QUESTION_ACCEPTED`、`QUOTE_CAPTURED`、`TRANSLATION_APPROVED`、`QUOTE_RELEASED`、`CORRECTION_SENT`。所有时间都必须携带时区，版本号从 1 开始递增，校验层不会替调用方改写输入。

## 事件载荷

- `QUOTE_CAPTURED`：还需包含 `speaker_id`, `source_language`。
- `QUOTE_RELEASED`：还需包含 `quote_level`, `release_version`。
- `CORRECTION_SENT`：还需包含 `supersedes`, `recipient_scope`。

同一事件标识的幂等与冲突处理属于上层业务服务职责；交换层只负责稳定报告结构、枚举、时间、版本和必需载荷问题。

## 服务层语义（`src/platform.js`）

`PressQuoteBoundary` 在契约层之上实现引语边界台的业务规则，关键动作（提问受理、片段采集、译文审批、片段发布、更正发出）都会发出通过契约校验的领域事件并计入审计日志。

- **场次与资质**：场次登记时区、默认引用级别与署名规则；记者按场次获得资质（证件号与可获得的引用级别），未获资质不得提问或取料。
- **引用级别**：`on_record`（可直接引用）、`background`（仅供背景理解）、`pending_confirmation`（等待确认）、`off_record`（不得报道，仅用于会后范围变更）。
- **接入**：实时与批量速记统一经 `ingest` 进入。相同外部标识且内容一致时复用原回执；内容冲突时隔离待审，原数据不被覆盖；乱序到达按发生时间还原场次时间线。
- **翻译**：翻译者提交译文，审批须由编辑或主办方作出，翻译者不能批准自己的译文；同一语言新译文获批后旧译文转为被取代。
- **确认与禁发**：等待确认的片段不得发布，须由专家或编辑方确认；片段可携带定时升级时点。禁发时点按场次指定时区解释，`tick` 到点释放禁发、升级待确认材料；`snapshot`/`restore` 保证服务重启后仍按原时点执行，`nextDueAt` 供运行方重挂定时器。
- **发布**：发布版本不可变，固定其采用的原文与已审批译文；`expected_version` 乐观并发控制保证两个编辑并发发布同一片段只形成一个当前版本。
- **更正**：专家更正不覆盖已发措辞，生成与旧引用相连的更正，送达范围取自已发布渠道，逐渠道跟踪送达情况。
- **范围变更**：会后改变范围只影响尚未发布的内容；已发布片段保持原版本，并为每个已发布渠道生成处理责任（如撤回、改为背景表述），可登记处理结果。
- **记者 API**：只返回记者有权获得的材料，未发布、禁发中、越级或不存在的内容统一返回 `not_available`，不泄露存在性；返回可引文字段、署名要求、事实附件与相关更正。
- **追溯**：主办方可以从一条报道引用追到提问、原话、翻译（含审批人）、确认记录及更正送达情况。
